# 📖 Lector de Documentos y Texto
App web que lee en voz alta textos y documentos (PDF, DOCX, TXT) usando voces neuronales de Edge-TTS.

## Uso local
pip install -r requirements.txt
streamlit run app.py

## Despliegue
1. Sube el repo a GitHub.
2. Entra a [share.streamlit.io](https://share.streamlit.io), conecta tu cuenta de GitHub.
3. "New app" → selecciona repo, rama `main`, archivo `app.py` → Deploy.
